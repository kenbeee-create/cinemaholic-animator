# ref02 クソメガネ（kusomegane.c）分析

- 素材：Instagram の画面収録（約58秒、うち本編 約47秒＋ブランド／告知 約10秒）
- 計測：UI部分を除いて切り出し、10fpsで差分を計測（ffmpeg＋Python）

## 数値
| 項目 | 実測 |
|---|---|
| 尺 | 本編 約47秒 ＋ 締め（ロゴ・グッズ告知）約10秒 |
| カット数 | 本編で **31ショット** |
| 平均カット長 | **1.5秒**（中央値1.4秒、最長3.6秒、3秒超は3回だけ） |
| 画面が完全に止まる最長時間 | **0.5秒**（常にどこかが変化） |
| 動いている場所 | 顔（口・目・汗のしずく）とテロップ。体はほぼ動かない |
| 音 | 声＋BGMが常に鳴っている。無音は最後だけ |
| 音量 | 約 -14 LUFS |

## 演出の特徴
- **2キャラのアップを交互に切り替える**（引きの絵は少ない）。同じ絵を寄り・引きで使い回している
- 汗のしずく（大量）・赤面などの **顔の漫画表現** で感情を出す
- テロップは画面中央に置き、**文字サイズと書体を大きく変える**：普段は小さめのドット風、オチ・ツッコミは画面幅いっぱいの太字や明朝（「殺ったろか」「血」「やめて？」）
- 単語単位で次々切り替え（「ネバネバも」→「あかんような」）
- 締め：作品名ロゴ＋エピソード名のタイトルカード → グッズ告知

## シネマホリックへの示唆
- テンポを出すなら **アップ中心・平均1.5秒カット**。絵は「寄り／引き」のトリミング違いで増やせる
- テロップの **サイズの振れ幅** がツッコミの笑いを作っている
- 締めに **毎回同じタイトルカード**（作品名＋回のタイトル）を置くとブランドになる
