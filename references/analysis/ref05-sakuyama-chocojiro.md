# ref05 サク山チョコ次郎（公式アニメ）分析

- 素材：TikTok の画面収録（本編 約19秒）
- 計測：画面部分だけ切り出し、10fpsで差分を計測
- 位置づけ：会話劇ではなく、**セリフなしの一発ギャグ型**。ゆるい・穏やかなトーンの参考

## 数値
| 項目 | 実測 |
|---|---|
| 尺 | 約19秒 |
| カット数 | **1回**（12.5秒で場面転換） |
| 画面が完全に止まる最長時間 | **1.4秒** |
| 変化の間隔 | 中央値0.2秒（音符などが常に動いている） |
| セリフ・テロップ | **なし**。音楽と効果音だけ |
| 音量 | -8.4 LUFS（音楽主体で、ほかの参考動画よりかなり大きい） |

## 演出の特徴
- 白っぽい背景にキャラと小道具（ラジカセ）だけ。情報が少ない
- 音符・波線などの **記号のアニメーション** で「音楽を聴いている」を表す。キャラはゆっくり首を揺らすだけ
- 小鳥がちょっかいを出す → ヘッドホンが吹っ飛ぶ → キャラがいなくなる、という **小さな出来事ひとつ** で落とす
- 最後にキャラが画面の端からちらっと戻ってくる（ループ再生と相性がいい）

## シネマホリックへの示唆
- 本編（60秒の会話）の参考ではなく、**本編の合間に出す短い投稿**（10〜20秒・セリフなし）の型として使える
  - 例：じょんどぅーがDVDを再生 → ごんべぇが寝落ち → じょんどぅーだけ泣いている
- 音符・汗・湯気などの **記号を動かす** だけで、キャラ本体を動かさなくても画面が生きる
- 落ち着いたトーンでも「1.5秒以上止めない」は守られている
