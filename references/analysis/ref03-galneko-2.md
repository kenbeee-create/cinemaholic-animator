# ref03 ギャル猫（neko_is_gal）別の回の分析

- 素材：Instagram の画面収録（約61秒）。自販機の前でしゃがむギャルと猫の会話
- 計測：画面部分だけ切り出し、10fpsで差分を計測

## 数値
| 項目 | 実測 | ref01 との比較 |
|---|---|---|
| 尺 | 約61秒 | ref01 は約100秒 |
| カット数 | **0**（冒頭の1回だけ。固定の引き1枚で最後まで） | 同じ |
| 画面が完全に止まる最長時間 | **1.2秒** | ref01 は2.1秒 |
| 変化の間隔 | 中央値0.5秒・最長1.3秒 | ほぼ同じ |
| 動いている場所 | 話者の口・目、小道具（扇風機・ペットボトル）の出し入れ、テロップ | 同じ |
| 音量 | -14.1 LUFS | 同じ |

## 演出の特徴（ref01 と共通＝このシリーズの型）
- 横長の画面を9:16の中央に置く。カメラは一切動かない
- テロップは話者の近くに、**話者ごとに色分け**（猫＝マゼンタ地、人間＝黒地）。数文字ずつ切り替え
- 冒頭だけ別ポーズ（立ち）→ すぐにいつもの座り位置へ。これが「始まった」合図になっている
- **小道具がひとつ出てくるだけで画面が変わって見える**（扇風機を出す→ペットボトルに替える）

## シネマホリックへの示唆
- 2本目でも同じ数値 → ギャル猫型は「固定画面＋口パク＋色分けテロップ」で確定
- 小道具の出し入れ（DVD・ポテチ・リモコンなど）は、少ない手間で画面に変化を作れる

## 回をまたいだ比較（ref01 と ref03）
- 舞台が回ごとに違う：ref01＝昼の歩道脇の段差、ref03＝夜の自販機の前
- ギャルの服も回ごとに違う（ref01＝オフショルダー、ref03＝緑のタンクトップ）
- **1話の中は固定画面1枚だが、回ごとに場所・時間帯・服を変えている**。フィードで流れてきたときに「前と同じ動画」に見えない
