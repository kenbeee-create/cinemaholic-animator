# ref01 ギャル猫（neko_is_gal）分析

- 素材：Instagram の画面収録（約104秒、うち本編 約100秒）
- 計測：本編部分を切り出し、10fpsで差分を計測（ffmpeg＋Python）

## 数値
| 項目 | 実測 |
|---|---|
| 尺 | 約100秒（60秒を超えても見られている） |
| カット数 | **ほぼ0**。最初から最後まで同じ引きの1ショット |
| 画面構成 | 9:16の中に **16:9の横長画面を上下黒帯で配置** |
| キャラの動き | 動くのはほぼ **話している猫の口と目、汗マーク** だけ。人間キャラはほぼ静止。呼吸・揺れは無い |
| キャラ領域が完全に止まる最長時間 | 約20秒 |
| テロップの切り替え | **約0.8秒ごと**（1秒あたり約1回）。テロップ領域が2.2秒以上止まることは無い |
| 音 | BGMほぼ無し。声が途切れず続き、間は0.5〜1秒程度 |
| 音量 | 約 -14 LUFS |

## 演出の特徴
- **テロップが主役**。1〜6文字の短いフレーズを、声に合わせてどんどん切り替える
- **話者ごとにテロップの色を固定**：猫＝マゼンタ地に白文字、人間＝黒地に白文字。位置も話者の近く
- 表情差分（目の形・汗）で感情を出す。ポーズ変更は数回だけ（最後に人間が猫を撫でる等）
- 思い出し・想像は **ふきだし（雲形）** で小さく出す
- 締めはタイトル（「ギャルネコ」）を大きく出してロゴ代わり

## シネマホリックへの示唆
- 「キャラを常に動かす」必要は無い。**口パク＋表情差分＋テロップの速い切り替え**で十分に見られる
- 固定の部屋の2ショットを基本にすれば、制作コストを最小にできる
- テロップの話者別カラーはすぐ真似できて効果が大きい
