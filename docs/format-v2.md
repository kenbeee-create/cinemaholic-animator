# 動画の構成 v2（提案・オーナー承認待ち）

> 承認されたら CLAUDE.md の「動画フォーマット」と `docs/opening.md` をこの形に書き換える。

## v1（いまの絵コンテ）が見られない理由
| 問題 | どこ |
|---|---|
| 最初の5秒にキャラも感情も出てこない（トーク画面→タイトル）。**最初の2秒で離脱される** | S1・S2 |
| 文字だけの画面が長い（5〜6秒）。「読む時間」は動画ではなく資料 | バックボーン・名言・処方箋 |
| 感情が平ら。共感→説明→名言→処方 で、**笑い・ドキッ・驚きが少ない** | 全体 |
| 最後が「コメントに書いて」だけ。**次の動画・過去の動画に行く理由がない** | S9 |

## v2の考え方（4つ）
1. **最初の2秒は「キャラの顔＋本音の一撃」**。説明しない・ロゴを出さない
2. **感情のジェットコースター**：笑い → 驚き → 自分ごと → 刺さる → 笑い。45秒で5回以上感情を動かす
3. **動きの密度**：1〜1.5秒ごとに何かが変わる（カット・寄り・記号・テロップ・挿絵）。**名言の数秒だけあえて止める**（静と動の差で刺さる）
4. **シリーズで回る仕掛け**：毎回のお約束＋次回のヒント＋過去回への導線

## 尺：45秒前後（長くても55秒）
短いほど最後まで見られ、繰り返し再生（ループ）も起きやすい。60秒にこだわらない。

## 新しい流れ
| # | 秒 | 名前 | 中身 | 動かす感情 |
|---|---|---|---|---|
| 1 | 0–2 | **フック** | ごんべぇの顔のアップで本音の一撃（特大テロップ・12文字以内）。1コマ目からキャラの顔と声 | 共感／「なに？」 |
| 2 | 2–7 | **あるある** | ごんべぇの愚痴を3カットで。1つは**脳内の挿絵**（会社で詰められるごんべぇ等）。じょんどぅーの噛み合わない返しで1笑い | 共感・笑い |
| 3 | 7–10 | **処方の合図** | じょんどぅー「…それ、効くやつあるよ」→ 錠剤「カラン」→低音「ジャン」→ 映画カード（2秒に短縮） | 期待 |
| 4 | 10–24 | **裏話3段** | 会話＋挿絵で。①もう1回見たくなる驚きの事実→ ごんべぇのリアクション → ②作った人の痛み → ③悩みとつながる →ごんべぇ黙る | 驚き×2 → 自分ごと |
| 5 | 24–31 | **名言** | 部屋が少し暗くなり、**1カットで止める**。名言＋ごんべぇの顔アップ（ため息→少しだけ照れ笑い） | 刺さる（静） |
| 6 | 31–38 | **処方箋** | 用量と副作用を「ボケ」で（例：副作用 月曜、ネクタイが首輪に見える）。はんこ「ドン」 | 笑い |
| 7 | 38–45 | **オチ＋次回** | 噛み合わないオチの一言 → カメラが部屋の「次回のヒント」の小物に寄る →「次の処方、わかった？」 | 笑い・続きが気になる |

## 最初の2秒：フックの型（毎回どれか1つ）
| 型 | 例 |
|---|---|
| 本音爆弾 | 「"みんな我慢してる"って何」 |
| 状況ギャグ | 床で大の字のごんべぇ。じょんどぅー「…死んでる？」 |
| 逆張り | 「疲れてる人は、この映画見ないで」 |
| ヤバい事実 | 「この映画、主人公の"もう1人"が最初から映ってる」 |
| 質問 | 「会社、何年目でつまらなくなった？」 |
ルール：2秒以内・12文字以内の特大テロップ・1コマ目にキャラの顔・音は1コマ目から（無音で始めない）

## 「驚き」の入れ方
性的なネタ（エッチな方向）は入れない（オーナー決定 2026-10-23）。驚きは**映画の裏話**で作る：
- 「知らなかった」事実（隠れた仕掛け・撮影の無茶・作った人の実体験）。必ず事実確認つき
- 「もう1回見たくなる」事実が一番強い（例：ファイト・クラブはタイラーが登場前に一瞬だけ映っている）

## 退屈させない動きのルール
- 1カット1〜2秒。**同じカメラ位置を2回続けない**
- 毎カットに「動き・記号・寄り」のどれかを入れる（スタジオの動き10種・記号13種で足りる）
- **10秒に1回「大きい瞬間」**（グッと寄る＋効果音＋特大テロップ）
- 文字だけの画面は最大2秒。裏話は文字カードではなく、**会話＋挿絵（カットアウェイ）**で見せる
- 例外：名言の3〜4秒だけ止める（BGMも少し下げる）

## シリーズで回る仕掛け
- **お約束**：「…効くやつあるよ」＋カラン→ジャン（ブランド音は変えない。鳴らす場所が7秒あたりに移るだけ）
- **カルテ番号**：左上に小さく「処方 No.07」。番号があると過去回を見たくなる
- **次回のヒント**：じょんどぅーの部屋に次の映画の小物を1つ紛れ込ませ、最後にカメラが寄る →「次の処方、わかった？」（コメントで当てっこ）
- **過去回への導線**：「前の処方の副作用、出た？」と前回の話を小ネタに入れる回を作る。プロフィールの再生リストを**症状別**（仕事・恋愛・休日…）に
- **CTA**：「悩みをコメントに」より答えやすい問いにする（「次の処方わかった人」「同じ症状の友だちに送って」）

## トーク画面とタイトルはどうするか
- **トーク画面**：冒頭から外す。使うなら途中の小ネタに（上司からのLINEを見て固まる、0.8秒）
- **タイトル「〇〇なそこの君に、いい薬を処方します。」**：冒頭から外して、7秒の「処方の合図」とひとつにする
- ロゴ（シネマホリック）は最後と、画面の端に小さく
