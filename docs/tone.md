# トーン（色・線・文字）

トーク画面・タイトル・テロップ・処方箋など、**キャラ以外の画面部品はすべてこのトーンにそろえる**。
値の実体は `renderer/templates/style.py`。色や文字を変えるときはそこだけを直せば全部に反映される。

## 方針
- キャラと部屋の絵（2Dフラット・太い輪郭線・アメリカンカートゥーン調・暗めの暖色）に合わせる
- 暗い背景に、クリーム色の文字と赤のアクセント。白（#FFFFFF）や原色は使わない
- 輪郭線はこげ茶に近い黒で、太め（1080px幅で6px）。文字にも輪郭線とずらした影をつける

話者の色：**ごんべぇ＝赤地にクリーム文字、じょんどぅー＝クリーム地にこげ茶文字**（トーク画面とテロップで共通）

## 文字
| 用途 | フォント |
|---|---|
| 見出し・タイトル・ロゴ | Noto Sans CJK JP Black |
| 吹き出し・テロップ | Noto Sans CJK JP Bold |
| 小さい文字 | Noto Sans CJK JP Medium |
| 名言など重い場面（予定） | Noto Serif CJK JP Black |

すべてSIL Open Font License（商用利用可）。丸ゴシック系（M PLUS Rounded 1c など）に変える場合は、TTFを `assets/fonts/` に置いて `style.py` の FONT_FILES を差し替える。

## 画面の安全地帯（1080×1920）
- 上230px：SNSのアカウント名など → 大事な文字を置かない
- 下（1560px〜）：キャプション・音源名 → 大事な文字を置かない
- 右（900px〜）：いいね・コメントのボタン列 → 文字や吹き出しを置かない。中央より少し左に寄せる

## 部品
- `assets/brand/logo_neon.png`：**タイトルアイコン**（ネオンの2人の顔＋「シネマホリック」）。アカウントのアイコン・タイトル用。作り方は `renderer/templates/neon_logo.py`。ネオンのピンクはブランドの差し色として、ロゴまわりだけに使う
- `assets/ui/logo.png`：ロゴ（錠剤＋シネマホリック＋CINEMA HOLIC）
- `assets/ui/pill.png`：錠剤アイコン
- `assets/ui/avatars/`：トーク画面のアイコン（キャラの基本画像から切り出し。リグ完成後に差し替え）
