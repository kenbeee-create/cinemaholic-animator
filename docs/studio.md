# スタジオ（仮想セットで会話シーンを作る）

部屋の絵を「セット」にして、ごんべぇとじょんどぅーを座らせ、カットごとにカメラ・セリフ・表情・動きを決めると、そのまま動く動画になる道具。
**毎回AIで絵を作らずに、同じセットとキャラで撮影する**ためのもの。

公開URL：https://kenbeee-create.github.io/cinemaholic-animator/tools/studio/
（スマホでもPCでも、ブラウザで開くだけ）

## できること
| 項目 | 内容 |
|---|---|
| カット | 秒数・話す人・テロップ（「/」で区切ると順に切り替わる）・特大テロップ |
| ごんべぇ | 目（いつもの半目／ジト目／目を閉じる／真顔／照れ笑い・ため息は素材待ち）、動き10種（うなずく・首かしげ・ため息で沈む・乗り出す・目をそらす・ビクッ など。頭と体が分かれている）、記号、姿勢（座り／立ち＝素材待ち）、しゃべる（口パク）。待機中は呼吸とまばたき |
| じょんどぅー | 動き10種（うなずく・首をかしげる・そっぽ など）、記号、しゃべる（口パク） |
| 記号 | 汗・赤面・怒りマーク・ガーン・どんより・♪・キラキラ・…・！・？・ビクッ・ため息の煙。「自動」は動きに合わせて出る。`assets/fx/<名前>.png` があれば画像を使い、無ければコードで描いた仮のもの |
| 小物 | 部品の棚（`assets/props/index.json`）から選んで置く。位置・大きさ・奥／手前・動き（ゆらゆら・ふわふわ） |
| 秒数の自動 | 「自動」でテロップの文字数から秒数を決める（JSON では `"dur": "auto"`） |
| 素材待ち | まだ画像が無い素材は、灰色の代役と札が出る。画像が届けば自動で本物になる |
| カメラ | カットの「はじめ」と「おわり」をプリセット（部屋全体・2ショット・それぞれのアップ・顔）から選ぶと、その間をなめらかに動く。画面をドラッグ／ホイールで「おわり」を手で調整。「カットの頭でグッと寄る」 |
| 部屋 | ランプ・テレビの光・ほこり・マグの湯気のオン・オフ、窓の外（星・雨・雪・ネオン）、映画ごとの照明の色 |
| 保存 | 「動画で保存」（その場で録画）。「JSONをコピー」→ 各話の `scene.json` |

## 高画質で書き出す（Claude 側）
`python3 renderer/templates/studio.py episodes/epXX-<slug>/scene.json output/epXX/scene.mp4`
スタジオと同じページを裏で動かして1コマずつ描くので、見た目はプレビューと同じ。

## 1本の動画のつなぎ方
各話の `episode.json` に場面を順に並べ、`python3 renderer/assemble.py episodes/epXX-<slug>/episode.json` で1本にする。
- 場面の種類：トーク画面（chat-maker）／タイトル（title）／会話（studio）／映画紹介（movie-card-maker）／文字の画面（card-maker：バックボーン・名言・処方箋）
- 効果音は各場面のタイミングに自動で入る。BGMは全体に流れ、声（voice.wav）があれば声の下で小さくなる。最後に音量を約-14 LUFSにそろえる
- 例：`episodes/ep00-sample/`（試作の通し）

## これから足すもの
- ごんべぇの立ち姿（`assets/characters/gonbe/stand.png`）、照れ笑い・ため息の目（`parts/eyes_tere.png`・`parts/eyes_sigh.png`）の画像
- 声を読み込んで、口パクを声の大きさに合わせる
