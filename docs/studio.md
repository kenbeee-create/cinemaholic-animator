# スタジオ（仮想セットで会話シーンを作る）

部屋の絵を「セット」にして、ごんべぇとじょんどぅーを座らせ、カットごとにカメラ・セリフ・表情・動きを決めると、そのまま動く動画になる道具。
**毎回AIで絵を作らずに、同じセットとキャラで撮影する**ためのもの。

公開URL：https://kenbeee-create.github.io/cinemaholic-animator/tools/studio/
（スマホでもPCでも、ブラウザで開くだけ）

## できること
| 項目 | 内容 |
|---|---|
| カット | 秒数・話す人・テロップ（「/」で区切ると順に切り替わる）・特大テロップ |
| ごんべぇ | 目（いつもの半目／ジト目／目を閉じる・ため息／真顔）、しゃべる（口パク）。待機中は呼吸とまばたき |
| じょんどぅー | 動き10種（うなずく・首をかしげる・そっぽ など）、しゃべる（口パク）。記号（？・…・汗）も自動 |
| カメラ | カットの「はじめ」と「おわり」をプリセット（部屋全体・2ショット・それぞれのアップ・顔）から選ぶと、その間をなめらかに動く。画面をドラッグ／ホイールで「おわり」を手で調整。「カットの頭でグッと寄る」 |
| 部屋 | ランプ・テレビの光・窓の星・ほこり・マグの湯気のオン・オフ、映画ごとの照明の色 |
| 保存 | 「動画で保存」（その場で録画）。「JSONをコピー」→ 各話の `scene.json` |

## 高画質で書き出す（Claude 側）
`python3 renderer/templates/studio.py episodes/epXX-<slug>/scene.json output/epXX/scene.mp4`
スタジオと同じページを裏で動かして1コマずつ描くので、見た目はプレビューと同じ。

## 1本の動画のつなぎ方（予定）
トーク画面（chat-maker）→ タイトル（title.py）→ 会話（studio）→ 映画紹介（movie-card-maker）→ 会話（studio）→ 名言・処方箋 → 締め。音（声・効果音・BGM）を乗せて1本にする仕組みはこれから。

## これから足すもの
- ごんべぇの立ち姿（入ってくる場面）、照れ笑い・ため息の顔
- 映画ごとの小物（ポスター・テーブルの上・窓の外）をセットに置く
- 声を読み込んで、口パクを声の大きさに合わせる
