# このプロジェクトの目的（2026-10-28 オーナー確認済み）

迷ったら、ここに戻る。

## 目的の3段
| 段 | 中身 |
|---|---|
| ① オーナーの目的（一番上） | **作り手として生きていく足場を作る。** 自分のキャラクターと作品で、数字の規模を持ち、映画・カルチャーの仕事につながる実績を残す |
| ② チャンネルの約束（作品の価値） | **ショート動画の代わりに、1本の映画を。** 他のキャラものと違う理由であり、「人を映画に動かせる作り手」という実績にもなる |
| ③ 手段 | **キャラクターのショートシリーズ**を入口にする。長尺・イベント・別の媒体へは、そのあと広げる |

## なぜショート動画か
- **キャラのシリーズにするため**：作り手の財産は1本の動画ではなく、ごんべぇとじょんどぅーというキャラクター。ショートは毎日会ってもらえる場所
- **入口にするため**：規模を作る最短の場所。仕事につなげるのは、その先

## 何ができれば達成か
- **数字の規模**（フォロワー・再生）
- **自分の仕事につながる**（映画・カルチャー領域の依頼・相談）
- 作品が本物である証拠として「観た」と言ってくれる人の数も見る

## 前提（制約）
- **公務員試験・転職と並行する。優先度は公務員が上。** 期限は決めない
- だから「がんばる計画」ではなく **「手を止めても止まらない仕組み」** にする（下の運用ルール）
- 公務員になった後は兼業の制限がある。収益化・仕事の受け方は、採用先の規程を確認してから決める

## 企画を採るか決める基準（3つ）
1. キャラが育つか
2. 規模につながるか
3. 映画を観させるか（今夜観られるか）

## 段階ごとのゴール（日付ではなく本数で区切る）
| 段階 | ゴール（ここまで来たら次へ） | 見る数字 | オーナーの作業 |
|---|---|---|---|
| 0. 回る状態 | **3本公開**。1本あたりのオーナーの作業が30分以内 | 作業時間 | 台本の承認・最後の確認・投稿 |
| 1. 型の検証 | **10本公開**（シーズン1）。残る冒頭・残る型がわかる | 3秒後に残る割合・最後まで見た割合・保存 | 同上＋月1回の画像まとめ作り |
| 2. シリーズ化 | **30本公開**。キャラ名で覚えられる（コメントで名前が出る）。2つ目の型（名作なのに観てない）を試す | フォロワー・コメントでのキャラ名・「観た」 | 同上 |
| 3. 規模と仕事の入口 | 規模の目標（段階2の結果を見て決める）。プロフィールに作品集と問い合わせ先 | フォロワー・依頼・相談 | 方針を決める |

## 運用ルール（低燃費モード）
- **作り置きと予約投稿**：時間がある週にまとめて作り、予約投稿で出し続ける。試験前は新しく作らない
- **オーナーの作業は3つだけ**：台本の承認／最後の確認／投稿（予約）。台本・事実確認・書き出し・素材の切り抜きはClaude
- **画像生成は月1回まとめて**（まとめ作りのリストを上から）
- **10本出すまでやらないこと**：新しいツールづくり、新しい型の追加、素材の大量生成
