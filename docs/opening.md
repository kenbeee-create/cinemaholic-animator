# 冒頭の作り方（トーク画面 → タイトル → いつもの部屋）

## 確定
- **毎回、トーク画面から始まる。** ごんべぇから、日常の不満のメッセージが届く
- 最後に「今日行くわ」系のひと言（金曜・土曜の夜に、じょんどぅーの家へ行く設定）
- 続いて **タイトル**：「〇〇なそこの君に、いい薬を処方します。」＋「シネマホリック」
- そのあと **いつもの部屋** の場面に移り、入りのひと言 → じょんどぅーの返し → 本題
- じょんどぅーは、このメッセージを読んで悩みを察している。だから部屋が映画仕様に準備されていても話の順番がおかしくない（`docs/episode-look.md`）

## 例
```
［トーク画面］
ごんべぇ：今日上司に〇〇で怒られた
ごんべぇ：俺まったく関係ないのに
ごんべぇ：上司〇してぇー
ごんべぇ：今日行くわ

［タイトル］
上司を〇したい そこの君に、
いい薬を処方します。
シネマホリック
```

## Scene1：トーク画面（0〜3秒）
- **ごんべぇのスマホの画面**として見せる（アニメの絵柄で描いたスマホ。後ろにその回の部屋がぼけて映る）。最後に「既読」がつく＝じょんどぅーが読んだ印
- 作り方：`renderer/templates/chat.py`（メッセージはJSONで差し替え。`renderer/templates/README.md`）
- メッセージは2〜4通。1通ずつ0.5〜0.8秒で出す。1通は20文字以内
- 通知音・送信音は毎回同じ（ブランド音のひとつ）
- 不満は、視聴者が「わかる」となる日常のもの（仕事・人間関係・お金・恋愛・生活）。**その回の悩みをここで出す**
- 画面のデザインは **オリジナルのトーク画面**。実在アプリ（LINEなど）のロゴ・アイコン・配色をそのまま再現しない
- ここがフィードで最初に見える1枚になる。**1通目で手が止まる言葉**を選ぶ

## Scene2：タイトル（3〜5秒）
- 型：「**〇〇な そこの君に、いい薬を処方します。**」＋ロゴ「シネマホリック」
- 〇〇には、トーク画面の不満をそのまま言い換えて入れる（例：上司を〇したい／休日が虚しい／何にも熱中できない）
- ブランド音：錠剤音「カラン」→ 低音「ジャン」。毎回同じ
- 作り方：`renderer/templates/title.py`（`worry` だけ差し替え）
- 背景は、その回の部屋を暗くした絵、または黒

## Scene3〜：いつもの部屋
- タイトルから部屋に切り替わる。ごんべぇが入ってきて「入りのひと言」（`docs/characters.md`）
- 部屋は、その回の映画に合わせて模様替え済み（`docs/episode-look.md`）

## 言葉のルール
- 「殺す」「死ね」などの言葉は **必ず伏せ字（〇）** にする。冗談の範囲で、実在の人への本気の攻撃に見えない言い方にする（SNSの規約と表示回数のため）
- 特定の会社・実在の人物・属性（性別・国籍など）への悪口にしない
