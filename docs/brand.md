# ブランド・ターゲット設計

## ターゲット
**映画をあまり見ない20〜30代・性別問わず。「なんか毎日がつまらない」と感じ、サブカルに興味はあるが深く踏み込めていない人**

推計母数：コア約280万人 / 拡張（〜30代後半）約400万人

## ペルソナ
### けんた（27歳・男性・会社員4年目）
- 地方の中規模都市出身 → 東京の大学 → 都内で就職・一人暮らし
- 高校時代は週3本DVDを借りるほど映画・音楽好き。社会人になって手放した
- Netflixは契約しているが「何見よう」で閉じる夜が続く
- **根本原因：「自分が何者か」を決める軸をまだ持っていない**（地元にも東京にも属しきれない）

### まりこ（34歳・女性・会社員8年目）
- 東京郊外出身。マーケ職でリーダーを任されている
- 「しっかりした人」として感情を出せない。最後に映画で泣いたのが思い出せない
- **根本原因：「仕事ができる自分」以外のアイデンティティを失っている**
