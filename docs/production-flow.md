# 動画の作り方（確定）

## 方式
**背景とキャラ2人を別々に作って重ねる**（カットアウトアニメ）。動画生成AIは使わない。
- 一度作った素材を毎回使い回す。毎回変えるのは、部屋の模様替え（照明・窓・ポスター・小物）・服・表情・テロップ
- 回想カットなど1回きりの絵だけ、1枚絵で生成してよい
- アップの絵は、同じ素材を拡大して切り抜いて作る（別に描かない）

## 素材の作り方：最初に「完成図」を1枚作る
大きさ・角度・座る位置をそろえるため、次の順で作る（プロンプトは `assets/keyvisual/PROMPTS.md`）。

| 順 | 作るもの | 置き場 |
|---|---|---|
| 1 | **完成図**：部屋のソファに2人が座っている絵（カメラ位置・2人の大きさ・座る位置をここで決める） | `assets/keyvisual/keyvisual.png` |
| 2 | 2人がいない部屋（完成図と同じ構図） | `assets/backgrounds/room_base.png` |
| 3 | ごんべぇだけ（完成図と同じポーズ・大きさ・位置、緑一色の背景） | `assets/characters/gonbe/sit_source.png` |
| 4 | じょんどぅーだけ（同上） | `assets/characters/johndoe/sit_source.png` |
| 5 | 表情の差分（目6種・口3種）：3・4の絵を編集して「目だけ」「口だけ」変える | `assets/characters/<id>/expressions_source/` |
| 6 | （後で）入ってくるときの立ちポーズ | `assets/characters/<id>/stand_source.png` |

- 画像の生成は、APIキーが無い間は **オーナーが Gemini / ChatGPT で生成してチャットに送る**。受け取った画像は character-rigger と art-director が切り抜き・層分け・登録をする
- 生成AIのマーク（右下のロゴなど）が入ったときは、大事なものを右下に置かない構図にしてあるので、切り抜きで消す

## 画面の配置（1080×1920）
- カメラはテレビの位置。2人はソファに並んで座り、テレビ（＝見ている人）の方を向いている。会話のときは少しお互いの方を向く
- **左：ごんべぇ、右：じょんどぅー**。2人とも横幅の中央80%（x 80〜880）に収める（右端はSNSのボタン列）
- 2人の顔は画面の高さの40〜60%あたり。上の方はテロップ、下の方は手前のローテーブル

## 毎回の流れ
| 順 | やること | 担当 |
|---|---|---|
| 1 | 台本 → 事実確認 → **承認** | scriptwriter → fact-checker → **オーナー** |
| 2 | トーク画面をメーカーで作る（`tools/chat-maker/`） | **オーナー**（または AI が chat.json を書く） |
| 3 | タイトルをテンプレートで作る（`renderer/templates/title.py`） | AI |
| 4 | 部屋の模様替えと服を決める（`look.json`） | art-director → オーナーが確認 |
| 5 | 声を入れる | 未定（自分で録音／AIの読み上げ） |
| 6 | カット・表情・テロップの指示書（`timeline.json`） | storyboarder |
| 7 | 合成して書き出し | motion-fx・sound-designer・animator |
| 8 | 検品 → **最終確認** | qa-reviewer → **オーナー** |
