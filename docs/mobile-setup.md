# スマホでClaude Codeを動かす方法

Claude Code はクラウド上で動かせるので、**PCが無くてもiPhoneから作業できます**。
セッションはクラウドのVMで動き続けるので、指示を出してアプリを閉じても作業は進みます。

## 必要なもの
- Claude の Pro / Max プラン
- GitHub アカウント（このリポジトリ）

## 初回だけやること
1. iPhoneのClaudeアプリを開き、下の **Code** タブを開く（ブラウザなら claude.ai/code）
2. GitHub と連携し、**Claude GitHub App** をこのリポジトリにインストールする
3. 環境（Environment）は最初に作られる **Default** でOK

## 毎回の使い方
1. Code タブ → このリポジトリを選んで新しいセッションを開始
2. 例：`/new-episode 休日が虚しい ロスト・イン・トランスレーション`
3. 台本の承認待ちで止まったら、内容を確認して「OK」または修正点を送る
4. 作業はブランチにコミットされる。差分を見て、問題なければPRを作ってマージ

## APIキーの置き方（画像生成・TTSを使うとき）
- **リポジトリにはコミットしない**
- claude.ai/code の環境設定で、環境変数またはネットワークシークレットとして登録する
  - `GEMINI_API_KEY`（画像生成）
  - `ELEVENLABS_API_KEY`（音声。自分で録音するなら不要）
- 環境のネットワーク設定で、使うAPIのドメインへのアクセスを許可する
  （初期の「Trusted」設定では外部APIが許可リストに無い場合がある）

## 環境のセットアップスクリプト（環境設定に貼る）
```bash
# 動画の書き出しに必要
sudo apt-get update && sudo apt-get install -y ffmpeg fonts-noto-cjk
```

## スマホ運用のコツ
- 音声の録音はiPhoneのボイスメモで録り、GitHubアプリかセッションにアップロードして
  `episodes/epXX-<slug>/audio/raw/` に置く
- 完成動画（`output/`）はgit管理外なので、セッション内で「動画をダウンロードできる形で渡して」と頼む
- 重い作業（全話の再書き出しなど）は依頼して放置でOK。終わったらアプリで確認
