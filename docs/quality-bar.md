# 品質基準（Quality Bar）

目標：ギャル猫・クソメガネのような「少し動く会話ショートアニメ」と並べて見劣りしないこと。
下の数値は **初期値**。reference-analyst が参考動画を分析したら実測値で上書きする。

## なぜ今のままだと「単調」になるのか
静止画＋テロップだと、画面の中で「何かが動いている時間」が足りない。
人気の会話アニメは、キャラが大きく動かなくても **常にどこかが小さく動いている**。

## 1. キャラの「生きてる感」（常時）
| 項目 | 基準 |
|---|---|
| 呼吸・揺れ | 体が常に上下 2〜4px、周期1.5〜2.5秒。2キャラで周期をずらす |
| まばたき | 3〜5秒に1回（ランダム）。じょんどぅーは目が毛に隠れているので「毛の揺れ」で代用 |
| 尻尾 | 待機中も揺れる。感情で速さを変える |
| 口パク | 最低3形（閉・半開・開）。音量に合わせて切り替え。聞き役は口を閉じる |
| 聞き役の反応 | 相手が話している間も、うなずき・目線・小さな傾きを入れる |

## 2. 表情とポーズ（セリフごと）
| 項目 | 基準 |
|---|---|
| 表情の種類 | 各キャラ最低6種：通常／驚き／ジト目／落ち込み／笑い／真顔 |
| ポーズ | 各キャラ最低3種：立ち／座り（ソファ）／指差し or 前のめり |
| 切り替え | 表情が変わる瞬間に 0.1秒の「ポップ」（拡大105%→100%） |

## 3. テンポ（編集）
| 項目 | 基準 |
|---|---|
| 平均カット長 | 1.5〜3秒。5秒を超える画面は作らない |
| カメラ | 引き／寄り（話者アップ）／超寄り（表情）を使い分ける |
| 間 | ボケ・オチの前に0.3〜0.5秒の無音 |
| 尺 | 45〜60秒。最後の3秒でループしやすい終わり方 |

## 4. テロップ
| 項目 | 基準 |
|---|---|
| 位置 | 画面下1/3より上・上下の約15%（UI領域）を避ける |
| 書式 | 太字ゴシック・白文字＋黒フチ。話者ごとに色の下線 or 名前 |
| 動き | 出現時にポップ（スケール or 下からスライド、0.15秒） |
| 強調 | キーワードだけ赤・大きく。1画面に強調は1つまで |
| 量 | 1枚2行・1行14文字以内 |

## 5. 漫画的エフェクト（1話に5〜10個）
汗マーク／怒りマーク／集中線／画面揺れ／ズームパンチ（急な寄り）／「…」の吹き出し／ハテナ／キラキラ／暗転・スポット

## 6. 音
| 項目 | 基準 |
|---|---|
| 効果音 | 1話に8〜15個。表情変化・テロップ強調・ツッコミに合わせる |
| BGM | 声が鳴っている間は自動で下げる（ダッキング） |
| ブランド音 | 冒頭（錠剤＋低音）と処方箋（スタンプ）は毎回同じ |
| 音量 | 最終 -14 LUFS 前後（SNS向け） |

## 7. 画質
1080×1920 / 30fps / H.264。パーツの継ぎ目・白フチ・ジャギーが目視で見えないこと。
