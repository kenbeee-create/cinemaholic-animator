# 品質基準（Quality Bar）

目標：ギャル猫・クソメガネのような「少し動く会話ショートアニメ」と並べて見劣りしないこと。
数値は参考動画2本の実測（`references/analysis/`）に基づく。参考動画が増えたら reference-analyst が更新する。

## 分析でわかったこと（最重要）
- 人気の2作とも、**キャラの体はほとんど動いていない**。動いているのは「話している方の口・目・汗」と「テロップ」
- 「動いて見える」の正体は **①テロップが約1秒ごとに切り替わる ②話者の表情差分 ③（クソメガネは）1.5秒ごとのカット** の3つ
- だから、キャラを常に揺らすより **テロップのテンポと表情差分に力を使う** のが費用対効果が高い

## シネマホリックのスタイル（2作のいいとこ取り）
| 場面 | 見せ方 | 参考 |
|---|---|---|
| 会話の基本 | 部屋の **固定の2ショット**（引き）。話す方だけ口パク・表情変化 | ギャル猫 |
| 感情の山・ツッコミ・核心 | 話者の **アップに切り替え**＋大きなテロップ | クソメガネ |
| バックボーン・名言 | 黒背景のテキストカード（シネマホリック独自） | — |
| 締め | 毎回同じタイトルカード（ロゴ＋回のタイトル）＋処方箋 | クソメガネ |

## 1. キャラの動き
| 項目 | 基準 | 実測の根拠 |
|---|---|---|
| 口パク | **必須**。話者だけ。最低2形（閉・開）、できれば3形 | 両作とも主な動きは口 |
| 表情差分 | **必須**。各キャラ最低6種（通常／驚き／ジト目／落ち込み／笑い／真顔）＋汗 | 両作とも表情と汗で感情を出す |
| 聞き役 | 基本は静止でよい。リアクションの瞬間だけ表情を変える | ギャル猫の人間キャラはほぼ静止 |
| 呼吸・揺れ・まばたき | **任意**（余力があれば）。入れるなら2〜3pxのごく小さな揺れ | 両作とも無し |
| ポーズ変更 | 1話に1〜3回で十分（オチなど） | ギャル猫は数回のみ |

## 2. テンポ
| 項目 | 基準 | 実測の根拠 |
|---|---|---|
| テロップの切り替え | **約1秒に1回**。2秒以上同じテロップを出さない | ギャル猫：0.8秒ごと・最長2.2秒 |
| 画面全体が止まる時間 | **最長2秒まで**（テロップ・口・カットのどれかが変わる） | ギャル猫2.1秒／クソメガネ0.5秒 |
| カット | 2ショット基本＋要所でアップ。全体の平均カット長 **2〜4秒**、アップ連打の山場は **約1.5秒** | クソメガネ：平均1.5秒 |
| 間 | オチ・核心の前に0.5〜1秒 | ギャル猫の無音は0.5〜1秒 |
| 尺 | 本編45〜60秒＋締め3〜5秒。会話が面白ければ60秒超も可 | ギャル猫は約100秒 |

## 3. テロップ（最重要）
| 項目 | 基準 |
|---|---|
| 長さ | **1枚1〜8文字程度の短いフレーズ**を声に合わせて切り替える（文を丸ごと出さない） |
| 話者の区別 | **話者ごとに色を固定**：ごんべぇ＝赤（パーカー色）地に白文字、じょんどぅー＝黒地に白文字（仮） |
| 位置 | 2ショット時は話者の近く。アップ時は画面中央。上下の約15%（UI領域）は避ける |
| サイズの振れ幅 | 普段は小さめ、ツッコミ・オチ・名言は **画面幅いっぱいの特大** に。1話2〜4回 |
| 書体 | 基本の書体1つ＋特大用の書体1つまで |
| 動き | 出現は0.1〜0.15秒のポップ程度。凝りすぎない |

## 4. 漫画的エフェクト
- 必須：**汗マーク・汗のしずく**（両作で最頻出）、**ふきだし（想像・思い出し）**
- 任意：集中線、画面揺れ、ズームパンチ、暗転スポット
- 目安：1話に3〜8個

## 5. 音
| 項目 | 基準 | 実測の根拠 |
|---|---|---|
| 声 | **途切れず続ける**。セリフ間の無音は0.5〜1秒まで | 両作とも声が密 |
| BGM | 入れる場合は声の下に小さく（ダッキング）。無しでも成立する | ギャル猫は無し・クソメガネは有り |
| 効果音 | 表情変化・ツッコミ・処方箋に。1話5〜12個 | — |
| ブランド音 | 冒頭（錠剤＋低音）と処方箋（スタンプ）は毎回同じ | — |
| 音量 | 最終 **-14 LUFS** 前後、ピーク -1dBTP 以下 | 両作とも約 -14 LUFS |

## 6. 画質
1080×1920 / 30fps / H.264。パーツの継ぎ目・白フチ・ジャギーが目視で見えないこと。

## 7. 画面比率
- 基本は縦9:16全面
- ギャル猫のように **9:16の中に横長の画面を置く** 方式も可（部屋の2ショットが収まりやすく、上下の黒帯にテロップやタイトルを置ける）。第1話のテストで両方を比べて決める
