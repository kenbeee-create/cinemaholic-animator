## この型のテンポ
- 20コマ・平均3秒。うち会話のコマは2ショットとアップを交互に、テロップは各コマの中で約1秒ごとに切り替える
- 長めのコマ（名言8秒・処方箋6秒）は、文字を1行ずつ出して画面を止めない

## まだ仮のもの

- 6：ため息の顔（作成中）
- 18：処方箋カードのデザイン（仮）
- 19：部屋が映画の色に変わる演出（色は仮）
