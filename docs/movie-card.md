# 映画紹介の画面（映画のタイトルが出たときに出す）

じょんどぅーが映画のタイトルを言ったら、**画面ごと切り替えて**、処方箋ふうの紹介画面を出す（イメージ調整中）。
- 左：大きなポスター／右：お薬の名前（タイトル）・公開年・上映時間・監督・効きめ（ひと言）・もらえる薬局（配信サービス）
- 右下：**白衣のじょんどぅー**がひと言（ふきだし）。はんこ「処方」
- イメージ：`docs/storyboard/movie_intro_mock.jpg`（作り直し：`python3 renderer/preview/movie_intro.py <movie.json> <出力.png>`）
- 白衣のじょんどぅーは、今はプログラムで白衣を描き足した仮。本番は服の素材として描き直す

（以前の試作：画面下からカードをせり上げる版 `renderer/preview/scene_demo.py`）

## カードの中身
| 項目 | 中身 | 決め方 |
|---|---|---|
| ポスター枠 | その回のポスター（下の「ポスターの扱い」） | art-director |
| タイトル・公開年・監督・上映時間 | 作品情報 | fact-checker が調べて確認 |
| ひと言の紹介 | あらすじではなく「どんな気持ちになる映画か」を16字前後のオリジナルの言葉で | scriptwriter |
| 観られる | 配信サービス名（見放題を先に、最大5つ＋「ほか〇サービス」）と、**情報の時点** | fact-checker |

## 配信情報の調べ方
- fact-checker が **Filmarks の作品ページ** を見て、配信サービスと種類（見放題／レンタル）を `episodes/epXX-<slug>/movie.json` に書く。必要なら各サービスの公式ページでも確かめる
- 配信は変わるので、カードに必ず「〇年〇月時点」を出す（Filmarks の更新時点）
- サービスのロゴは使わず、文字で出す（商標のため）
- 書式は `episodes/ep01-fight-club/movie.json`

## ポスターの扱い（未定・オーナーの判断待ち）
- 今のルール（CLAUDE.md）では、実在の映画ポスターは使わない。カードのポスター枠には、部屋の壁に飾るのと同じ **オリジナルのポスター絵** を入れる
- 公式ポスターを使う場合は、著作権（引用の条件）と、SNSの権利者からの申し立てのリスクがある
