# 部品の棚：漫画の記号

ChatGPTで「記号シート」（PROMPTS_ChatGPT.md ⑧）を作り、`python3 scripts/slice_sheet.py <シート> fx` で切り分けるとここに入る。
ファイルがある記号はスタジオで自動的に画像に切り替わる。無い記号はコードで描いた仮のものが出る。
名前：sweat 汗 / anger 怒りマーク / gaan ガーン / gloom どんより / note 音符 / sparkle キラキラ / exclaim ！ / question ？ / steam ため息の煙
（赤面は頬の位置に合わせる必要があるのでコードで描く。…と驚きの線も単純なのでコード）
