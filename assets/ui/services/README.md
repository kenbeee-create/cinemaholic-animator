# 配信サービスのアイコン

映画紹介の画面の「もらえる薬局」で使う。ファイル名は `renderer/preview/movie_intro.py` の SERVICES の id に合わせる。
| サービス | ファイル名 |
|---|---|
| Netflix | netflix.png |
| U-NEXT | unext.png |
| WOWOWオンデマンド | wowow.png |
| TELASA | telasa.png |
| Prime Video | primevideo.png |
| DMM TV | dmmtv.png |
| Disney+ | disneyplus.png |
| Hulu | hulu.png |
| ABEMA | abema.png |
| Lemino | lemino.png |
| FOD | fod.png |
| J:COM STREAM | jcom.png |
| TSUTAYA DISCAS | discas.png |
| music.jp | musicjp.png |

- 正方形のPNG（512×512 くらい）。各サービスの公式サイトのプレスキット・ブランドガイドラインから入手し、ガイドラインの使い方（色・余白・改変しない）に従う
- ファイルが無いサービスは、サービスの色の四角に名前を入れた仮のアイコンが出る
